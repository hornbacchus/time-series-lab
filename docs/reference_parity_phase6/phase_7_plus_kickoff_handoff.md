### Operational mode — TWO-TIER VALIDATION ARRANGEMENT

**Tier 1: Chat-with-web-search upstream decision support
(concurrent with work program).**
- Per technique, Chat proposes: reference package selection,
  tolerance band specification, fixture characteristics,
  boundary of validity
- Web search augments Chat's training-data knowledge with
  current papers, R package documentation, statsmodels
  documentation, academic surveys
- Chat's upstream decisions documented with **explicit
  provenance metadata** (web search queries used, sources
  consulted, confidence assessment per decision)
- For techniques where parity isn't feasible: Chat proposes
  blended validation strategy with same provenance discipline

**Tier 2: External expert review AFTER work program completes.**
- User commits to recruiting external expert resource (Morgan
  Stanley quant colleague / external consultant / academic
  collaborator)
- Expert review timing: **AFTER all 75 techniques (or maximally
  completed work program; remainder via blended) are validated
  AND add-in is fully operational**
- Expert reviews ALL upstream decisions and validation outputs
  at end of work program
- Expert findings produce course-correction; affected techniques
  remediated; deep-dive per technique at expert review time
- Expert review is **NOT incremental; NOT per-technique; NOT
  mid-work-program**

**Per-technique workflow during work program** (6 steps):
1. Chat proposes upstream decisions with provenance metadata
2. User ratifies or contests
3. If contested, Chat redrafts; iterate to ratification
4. Code executes parity work (or blended validation if parity
   not feasible)
5. Validation output documented with provenance metadata
6. Technique enters **validated-pre-expert-review status**;
   available for publication with mandatory disclosure
   (see PUBLICATION POLICY below)
