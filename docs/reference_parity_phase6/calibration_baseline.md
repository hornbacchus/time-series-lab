## §4 Living baseline maintenance protocol

**Amendment additions:** append new amendment to §2 register +
§3 content; date-stamp; cross-reference surfacing sub-session
+ commit hash. Format: A4, A5, ... sequential per surfacing
order.

**Amendment supersession:** mark prior amendment status =
"superseded by A<N>"; append superseding amendment with
explicit cross-reference to superseded entry; preserve audit
trail (do NOT delete superseded content).

**Amendment merges:** if multiple amendments converge to same
recalibration outcome (e.g., A4 + A5 produce identical
threshold change), mark both status = "merged into A<N>";
authoritative content lives at single merged entry.

**Activation criteria for FUTURE recalibration moments:**
amendment candidate density triggers next moment; specific
density threshold deliberately NOT codified to preserve
optionality (per chat-instance-seam recalibration institutional
precedent: structural decisions inherit Code+Chat judgment at
trigger time, not pre-locked criteria). Code surfaces density
observation at sub-session closeout; Chat dispositions
activation timing.

**Amendment closure:** if amendment is absorbed into master
plan via v1.4+ amendment cycle, mark status = "closed at
master plan v<X>"; preserve content at this baseline as
archaeological reference; remove from active recalibration
agenda.
