## What It Does
This technique performs official-statistics-grade seasonal adjustment using the U.S. Census Bureau's X-13ARIMA-SEATS program. It offers two decomposition methods: X-11 (the default — the moving-average-based algorithm national statistical agencies use to publish seasonally-adjusted economic data) and SEATS (a model-based alternative that derives the seasonal and trend components from the fitted regARIMA model's spectral properties). Both pre-adjust the series for outliers and calendar effects with an automatic regARIMA model, and both return the seasonally-adjusted series along with its trend, seasonal, and irregular components.

## When to Use It
- You want seasonal adjustment to the standard used by official statistical agencies (X-11 is the default and the most widely-published method).
- You want to compare the moving-average decomposition (X-11) against the model-based one (SEATS) on the same series.
- You're working with monthly or quarterly economic data and want a defensible, widely-accepted adjustment with automatic outlier and calendar pre-adjustment.
- Use this technique for official-grade monthly/quarterly adjustment; use `stl_decompose` or `classical_decompose` for a lighter, dependency-free decomposition.

## How to Read the Result
The output is four series — the seasonally-adjusted series, the trend, the seasonal factors, and the irregular component — plus a seasonal-strength measure. The method control selects the decomposition: X-11 (the default) reads the Census D-tables (D11 seasonally-adjusted, D12 trend, D10 seasonal, D13 irregular); SEATS reads the model-based S-tables (S11, S12, S10, S13), the same four components derived from the regARIMA model rather than from moving averages. The two methods give similar but not identical results — on the airline series the seasonal strength is 0.978 under X-11 and 0.990 under SEATS, with the adjusted levels differing by a few units — so choosing between them is a methodological judgment (X-11 is the agency default; SEATS can give smoother components when the series is well-described by its ARIMA model). Two behaviors to know: by default the model fits only the most recent 120 observations (a rolling concurrent window, in the style of agency practice), so on a longer series the oldest data are dropped with a warning — set the fit window to 0 to use all available data.

## Related Techniques
- *(use after)* analyze the seasonally-adjusted series or the irregular component for residual signal.
- *(alternatives)* `stl_decompose` (Loess-based, no external dependency); `classical_decompose` (simplest); `mstl_decompose` (multiple seasonal periods).

## Technical Detail
The engine calls the Census X-13 binary, writing a specification with an automatic regARIMA pre-adjustment model (`automdl`) for outliers and calendar effects, then either an `x11` or a `seats` decomposition block depending on the method. X-11 mode returns the Census D-tables — D11 (seasonally adjusted), D12 (trend), D10 (seasonal), D13 (irregular); SEATS mode returns the analogous S-tables (S11, S12, S10, S13) computed from the fitted model. Both populate the same output contract plus a computed seasonal strength; the higher-level X-13 diagnostics (M and Q statistics, sliding spans, revision histories) are not extracted. The SEATS path is validated against R's `seasonal` package — an independent wrapper of the same Census binary — confirming the engine correctly drives the binary and extracts the S-tables (the agreement is to machine precision); this establishes plumbing-correctness against the reference standard, not an independent re-derivation of the SEATS algorithm itself. **Dependency note:** this technique requires the Census X-13 binary to be present on the machine (it is located via an environment variable, a bundled `resources/x13/` folder, or the system path). The binary is not distributed with the repository — a fresh clone will not run X-13 until the binary is installed.
*Reference run:* airline_passengers.csv (144 monthly observations), all data (fit window 0), Balanced — X-11 (the default): seasonal strength 0.978, adjusted-series tail near 488; SEATS (method = seats): seasonal strength 0.990, adjusted-series tail 490.9, trend tail 493.0; the engine's SEATS output matches R `seasonal::seas()` to machine precision (relative difference about 1e-11).
