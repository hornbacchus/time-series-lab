# Hidden Markov Model (HMM)

## What It Does

A Hidden Markov Model (HMM) describes a system that transitions between a finite number of hidden states, where each state produces an observation according to a state-specific probability distribution. While closely related to Markov switching models, HMMs emphasize the general framework of hidden state inference and are widely used beyond time series -- in speech recognition, genomics, and pattern classification -- wherever sequential data has latent structure.

## When to Use It

- Your sequential data is generated by a system that switches between discrete hidden states
- You want to segment a time series into distinct behavioral phases
- The observations at each time point depend on an underlying state you cannot directly observe
- You need to decode the most likely sequence of hidden states (e.g., classifying each time point)
- Applications include activity recognition, market regime detection, and signal processing

## Key Assumptions

- The number of hidden states is fixed and known (or selected via model comparison)
- The hidden state sequence follows a first-order Markov chain
- Observations are conditionally independent given the hidden states (output independence)
- The emission distribution for each state is correctly specified (Gaussian, Poisson, categorical, etc.)
- The system is time-homogeneous (transition and emission parameters do not change over time)

## Outputs

- **Decoded state sequence**: the most likely hidden state at each time (via Viterbi algorithm or posterior decoding)
- **State posterior probabilities**: probability of each state at each time given all data
- **Transition matrix**: probabilities of switching between states
- **Emission parameters**: the distribution parameters for each state (mean, variance, etc.)
- **Log-likelihood and information criteria**: for model comparison and selecting the number of states

## Technical Details

**Model components**: An HMM with K states is defined by:
- **Initial distribution**: `pi_i = P(S_1 = i)` for i = 1, ..., K
- **Transition matrix**: `A_{ij} = P(S_t = j | S_{t-1} = i)`
- **Emission distributions**: `b_j(y_t) = P(Y_t = y_t | S_t = j)`, e.g., `N(mu_j, sigma_j^2)` for Gaussian HMMs

**Three fundamental problems**:

1. **Evaluation** (likelihood computation): Given parameters, compute `P(Y_1, ..., Y_T)`.
   - **Forward algorithm**: Define `alpha_t(j) = P(Y_1, ..., Y_t, S_t = j)`.
   - Initialization: `alpha_1(j) = pi_j * b_j(y_1)`
   - Recursion: `alpha_t(j) = [sum_i alpha_{t-1}(i) * A_{ij}] * b_j(y_t)`
   - Termination: `P(Y) = sum_j alpha_T(j)`

2. **Decoding** (most likely state sequence): Given data, find `argmax_{S_1,...,S_T} P(S_1,...,S_T | Y_1,...,Y_T)`.
   - **Viterbi algorithm**: Like the forward algorithm but replaces sum with max.
   - Define `delta_t(j) = max_{S_1,...,S_{t-1}} P(S_1,...,S_{t-1}, S_t=j, Y_1,...,Y_t)`.
   - Recursion: `delta_t(j) = max_i [delta_{t-1}(i) * A_{ij}] * b_j(y_t)`
   - Backtrack from `argmax_j delta_T(j)` to recover the optimal path.

3. **Learning** (parameter estimation): Estimate pi, A, and emission parameters from data.
   - **Baum-Welch algorithm** (EM for HMMs):
   - E-step: Compute forward (`alpha`) and backward (`beta`) variables, then:
     - `gamma_t(j) = P(S_t = j | Y) = alpha_t(j) * beta_t(j) / P(Y)`
     - `xi_t(i,j) = P(S_t = i, S_{t+1} = j | Y)`
   - M-step: Update `A_{ij} = sum_t xi_t(i,j) / sum_t gamma_t(i)` and emission parameters using `gamma_t(j)` as weights.

**Backward algorithm**: `beta_t(i) = sum_j A_{ij} * b_j(y_{t+1}) * beta_{t+1}(j)`, with `beta_T(i) = 1`.

**Scaling**: Forward and backward probabilities can underflow for long sequences. Log-space computation or scaling factors (dividing by `sum_j alpha_t(j)` at each step) prevent this.

**Posterior decoding** (alternative to Viterbi): Assign each time point to the state with highest `gamma_t(j)`. This maximizes the expected number of correct states, whereas Viterbi maximizes the probability of the entire path.
