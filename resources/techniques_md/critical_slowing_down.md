## What It Does
Critical Slowing Down looks for early-warning signals that a system is approaching a tipping point (a bifurcation). The theory: as a dynamical system nears a critical transition, it recovers more slowly from small perturbations, which shows up as *rising* lag-1 autocorrelation and *rising* variance in a rolling window. The technique detrends the series, computes these rolling indicators, measures whether each is trending up (a Kendall-tau rank correlation against time), combines them into a composite score, and tests that score against bootstrapped surrogates for significance. Outputs are the indicator trends, their significance, a composite early-warning score, and the rolling indicator series.

## When to Use It
- You want to monitor a series for signs of an approaching regime shift or instability, rather than characterize regimes that already exist.
- You have a reasonably long series and want the standard ecology/complex-systems early-warning indicators (autocorrelation and variance trends).
- You're stress-monitoring and want a single composite signal with a significance test attached.
- Use this to detect an *approaching* transition; use `markov_switching` / `hmm` / `tar_setar` to model transitions that have already occurred. Treat it as a monitoring diagnostic, not a forecast.

## How to Read the Result
Read three things together, and read them sceptically. First, the indicator trends: a positive Kendall-tau on lag-1 autocorrelation and on variance is the canonical signature of critical slowing down. On the saddle-node reference (a system genuinely approaching a bifurcation), tau is +0.151 for autocorrelation and +0.108 for variance — both rising, as theory predicts. Second, the significance: each indicator's trend is tested against AR(1)-surrogate bootstraps, and here both surrogate p-values are weak (0.39 and 0.43) — *not* individually significant. Third, the composite: it reads +1.67σ ("critical"). The crucial honesty point is that contrast — the composite can flag "critical" while no individual indicator's trend is surrogate-significant, so a "critical" composite is a prompt to look closer, not a confirmed alarm. Early-warning signals are descriptive, not predictive: they can false-alarm, and not every transition is preceded by them (their out-of-sample value on financial data specifically is contested). And the detrending choice materially affects the indicators — try more than one before drawing a conclusion.

## Related Techniques
- *(use after)* if a signal appears, characterize the regimes themselves with `markov_switching`, `hmm`, or `tar_setar`.
- *(alternatives)* the regime models above for transitions that have already happened; volatility models (`garch`, `stochastic_volatility`) for a different lens on rising instability.

## Technical Detail
A four-stage pipeline (numpy/scipy), following the Scheffer (2009) / Dakos (2012) early-warning framework. First detrend (Gaussian kernel smoothing by default; first-difference or linear are alternatives), with the smoothing bandwidth defaulting to a data-dependent value (about one-tenth of the series length). Then compute rolling lag-1 autocorrelation and rolling variance over a moving window. Then measure each indicator's trend by Kendall-tau rank correlation against time. Finally combine the indicators into a composite (an equal-weight z-score by default, or Fisher's method) and test significance by generating AR(1) surrogate series and bootstrapping empirical p-values; the surrogate count auto-caps to a data-dependent ceiling to bound memory use. This is the most externally-validated technique in this block — it is cross-package validated against the `ewstools` library, so the indicator computations have an independent reference (unlike the self-validated neural model in this block).
*Reference run:* the parity fixture critical_slowing_down_saddle_node.npz (n=2,000, a stochastic system approaching a saddle-node bifurcation), Gaussian detrending, p-values on, Balanced, seed 42 — composite early-warning score +1.67σ ("critical"); Kendall-tau +0.151 for lag-1 autocorrelation and +0.108 for variance (both rising toward the bifurcation, the canonical signature), but surrogate p-values 0.39 and 0.43 (individually not significant — the honest nuance); detrending bandwidth 200, rolling window 1,000, Kendall lookback 500, surrogate count auto-capped to 200.
