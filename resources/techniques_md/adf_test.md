# Augmented Dickey-Fuller Test

## What It Does

The Augmented Dickey-Fuller (ADF) test checks whether a time series has a **unit root**, which would indicate it is non-stationary. Non-stationary series wander without returning to a fixed mean, making them unsuitable for many statistical models without differencing. The test's null hypothesis is that the series has a unit root (is non-stationary); rejecting it provides evidence of stationarity.

## When to Use It

- Before fitting ARIMA models, to determine the differencing order d
- You want to verify whether a series is trend-stationary or difference-stationary
- You need to check if two series might be cointegrated (both must be I(1))
- You suspect a trending series might be stationary around a deterministic trend
- As part of a standard time series analysis workflow before modeling

## Key Assumptions

- The series is generated by an AR process (possibly with a unit root)
- The augmentation lags are sufficient to capture the autocorrelation structure, producing white noise residuals
- The series does not contain structural breaks (these can cause the test to fail to reject even when no true unit root exists)
- The sample size is large enough for the test to have adequate power

## Outputs

- **Test statistic**: the t-statistic for the unit root coefficient
- **p-value**: probability of observing the test statistic under the null hypothesis of a unit root
- **Critical values** at 1%, 5%, and 10% significance levels
- **Decision**: reject or fail to reject the null hypothesis of a unit root
- **Selected lag order**: the number of augmentation lags used

## Technical Details

**The basic Dickey-Fuller test**: Consider the AR(1) process `Y_t = rho * Y_{t-1} + e_t`. If `rho = 1`, the series has a unit root. The test reparameterizes as:

`Delta Y_t = gamma * Y_{t-1} + e_t`

where `gamma = rho - 1` and `Delta Y_t = Y_t - Y_{t-1}`. The null hypothesis is `H0: gamma = 0` (unit root) vs. `H1: gamma < 0` (stationary).

**Augmentation**: The basic test assumes AR(1) errors. To handle higher-order autocorrelation, p lagged differences are added:

`Delta Y_t = alpha + beta*t + gamma * Y_{t-1} + sum_{j=1}^{p} delta_j * Delta Y_{t-j} + e_t`

where:
- `alpha` is a constant (intercept)
- `beta*t` is a deterministic time trend
- The lagged differences `Delta Y_{t-j}` absorb higher-order autocorrelation

The test statistic is `tau = gamma_hat / SE(gamma_hat)`.

**Three model variants**:
1. **No constant, no trend**: `Delta Y_t = gamma * Y_{t-1} + lags + e_t`. Use when the series has zero mean under stationarity.
2. **Constant, no trend**: `Delta Y_t = alpha + gamma * Y_{t-1} + lags + e_t`. Use for series with a non-zero mean but no trend.
3. **Constant and trend**: `Delta Y_t = alpha + beta*t + gamma * Y_{t-1} + lags + e_t`. Use when the series might be stationary around a deterministic trend.

**Critical values**: The test statistic does not follow a standard t-distribution under the null. Instead, it follows a Dickey-Fuller distribution, which is left-skewed. Critical values (tabulated by Fuller, or computed by MacKinnon's response surface regression) depend on the model variant and sample size. For example, at 5% significance with a constant: approximately -2.86 for n=100.

**Lag selection**: The number of augmentation lags p can be chosen by:
- **AIC/BIC**: select p that minimizes the information criterion
- **t-sig method**: start with a large p_max, remove the last lag if insignificant, repeat
- **Default**: `p_max = floor(12 * (n/100)^{1/4})`

**Limitations**: The ADF test has low power against near-unit-root alternatives (rho close to 1). It may also fail in the presence of structural breaks, where the KPSS or Zivot-Andrews tests may be more appropriate. Using it alongside the KPSS test (which has stationarity as its null) provides a more complete picture.
