## What It Does
This technique produces a distributional forecast of the entire US Treasury yield curve, conditioned on a set of economist macro projections. It is a large Bayesian VAR with stochastic volatility (BVAR-SV): the VAR captures the joint dynamics of the yield curve and macro variables, the stochastic-volatility component lets the shock variances drift over time (so the model widens in volatile regimes and tightens in calm ones), and the macro projections enter as conditioning information that pins the forecast paths to a chosen scenario. Rather than a single point forecast it returns percentile bands (5th / 25th / 50th / 75th / 95th) for every maturity at every horizon. It is purpose-built and takes its inputs from a structured workbook, not a pasted series.

## When to Use It
- You want a full-curve, macro-conditioned yield forecast with honest distributional bands, not a single path.
- You have economist macro projections (the conditioning scenario) and want a yield path consistent with them.
- You're producing a published rates view and need the forecast's uncertainty quantified across maturities and horizons.
- Use this when conditioning on macro is the point; use the generic `bvar` for an unconditional shrinkage VAR on any system, or `var` / `vecm` for smaller unconditioned systems.

## How to Read the Result
The output is a percentile fan for each maturity. On the reference run the 10-year median one quarter ahead is 4.18%, with a 5th-to-95th band of 3.62% to 4.74% — read the spread as the model's stated uncertainty, which widens at longer horizons and in higher-volatility regimes. The median is the central case conditional on the scenario; the bands are the distribution around it. Critically, check the convergence diagnostics before relying on a run: the sampler is a single-chain Gibbs sampler and reports minimum effective sample size (ESS) and a Geweke z-statistic. On the reference run these were weak (ESS_min 10.7, Geweke max |z| 14.8) — a signal that the default draw count was not enough for stable tail estimates and that the Thorough preset (more draws) is warranted before publishing off the percentile bands. When the diagnostics are weak, treat the median as more robust than the extreme percentiles.

## Related Techniques
- *(use after)* read the forecast against a separate `pca_analysis` of the realized curve to sanity-check the implied level and slope of the path.
- *(alternatives)* `bvar` for an unconditional Bayesian VAR (the generic engine underneath this); `var` / `vecm` for smaller unconditioned systems; `stochastic_volatility` for the SV mechanism in isolation. The breakeven-payrolls technique is the other purpose-built workbook-input member.

## Technical Detail
The model is a BVAR with stochastic volatility in the Carriero-Clark-Marcellino tradition, estimated by Gibbs sampling. Inputs come from a three-sheet workbook (historical yields and macro data; the economist projections that define the scenario; and configuration), supplied via the workbook path — there is no pasted-series input. A Minnesota prior governs the VAR coefficients through three shrinkage hyperparameters: λ1 overall tightness (default 0.2), λ2 cross-equation shrinkage (0.5), and λ3 lag-decay (1.0). The macro projections condition the forecast, with `projection_uncertainty` (default 0.25) controlling how tightly the paths are pinned to them. Sampling defaults to 10,000 draws with 3,000 burn-in, 50 forecast paths per retained draw, and a 1,000-draw subsample for the path distribution; a fixed seed makes runs reproducible.
On validation, this is the most thoroughly checked technique in the catalog — but the checks are tiered by layer and the scope matters. The VAR coefficient estimation is verified to machine precision against an independent cross-language computation (an algebraic route in R), and the Minnesota prior matches its documented closed form exactly. The stochastic-volatility layer was checked against the R `stochvol` package: the volatility *dynamics* (persistence) agree, but the *level and scale* of the latent volatility process differ — a genuine cross-implementation divergence that is disclosed, not a bug. The emitted yield paths are verified internally consistent (the conditioning is exact, confirmed against a discriminating control) but have no independent cross-source reference — no external package produces a comparable conditional BVAR-SV forecast to check them against. So the engine math is independently validated; the final conditional paths are internally verified but not externally cross-checked. Two advanced seasonal and import-output shrinkage hyperparameters exist in the engine but are not exposed in the dialog.
*Reference run:* read from a prior real run (`bond_yield_forecast_input_06042026.xlsx`, baseline scenario, Balanced, seed 42 — not re-run, as the MCMC is heavy): BVAR-SV with 7,000 kept draws (10,000 − 3,000 burn-in), 143 quarterly observations, 4 lags, an 8-quarter horizon across 34 maturities, 50 paths per draw, roughly 60 seconds. Representative path: 10-year H+1 median 4.18% (p05 3.62 / p25 3.95 / p75 4.40 / p95 4.74), 2-year H+1 median 3.53%. Convergence diagnostics were weak on this run (ESS_min 10.7, Geweke max |z| 14.8), arguing for more draws before publication.
